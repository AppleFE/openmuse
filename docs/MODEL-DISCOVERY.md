# OpenCodex 모델 목록 자동 갱신

OpenMuse 0.6.1부터 `OPENCODEX_BASE_URL`과 `OPENCODEX_API_KEY`가 설정되어 있으면 해당
OpenAI 호환 데이터 API의 `GET /models`를 서버 시작 시와 60초마다 호출합니다.
예를 들어 Base URL이 `http://100.80.94.16:20100/v1`이면 `/v1/models`를 조회합니다.
새 모델을 추가하려고 `.env`를 다시 편집하거나 OpenMuse를 재시작할 필요가 없습니다.

- 채팅의 모델 선택 팝업과 설정의 기본 모델 영역에서 **모델 목록 새로고침**으로 즉시 갱신합니다.
- 모델 개수, 마지막 정상 갱신 시각, 조회 오류를 표시합니다. 열린 웹앱에도 최신 목록이 반영됩니다.
- `OPENMUSE_MODELS`의 기존 모델 ID·이름·비활성화 설정과 기본 모델 선택을 유지합니다.
  다른 제공자의 수동 설정 모델도 유지합니다. 0.7.0부터 제공자가 이미지 지원을 알리면 기존 모델에도
  `vision`을 반영합니다. 그 밖의 기존 프로필 기능은 제공자 지원 범위 내에서 유지합니다.
- 새 모델은 제공자 모델 ID에서 안정적인 내부 ID를 생성하며 기본 모델이나 팀 역할에 지정할 수 있습니다.
- OpenCodex에서 삭제된 자동 추가 모델은 목록에서 빠집니다. 수동 등록 모델은 ‘OpenCodex 목록에서 제거됨’으로
  표시되며 선택할 수 없습니다. 이미 실행 중인 작업의 모델 스냅샷은 변경하지 않습니다.
- 일시적인 조회 실패, 잘못된 응답, 시간 초과 시 마지막 정상 목록을 유지합니다.
  해당 목록은 DB에도 저장해 OpenMuse 재시작 후 연결 장애에도 복구합니다.
  엔드포인트나 API 키를 변경하면 이전 연결의 캐시를 재사용하지 않습니다.
- 조회 요청은 최대 8초, 응답은 최대 2 MiB/2,000개로 제한하고 리다이렉트를 따르지 않습니다.
  API 키와 제공자 오류 본문은 클라이언트에 반환하지 않습니다. 목록에 있다는 것이 모든 모델의 추론 성공을 보장하지는 않습니다.

기존 수동 목록만 사용하려면 `.env`에 `OPENCODEX_MODEL_DISCOVERY=false`를 지정하고 서버를 재시작하세요.
인증된 워크스페이스 API의 `POST /api/agent/models/refresh`로 즉시 갱신할 수도 있습니다.
`GET /api/agent/models`의 배열 응답 형식은 유지하며 `/api/agent`에는 `modelCatalog` 상태가 추가됩니다.
