# 스킬

OpenMuse 0.4부터 작업 지침과 참고 파일을 스킬로 보관하고 채팅에서 `/스킬이름 요청 내용`으로 호출할 수 있습니다. OpenMuse 서버의 데이터 디렉터리에 저장하므로 별도 클라우드나 프로젝트 키가 필요하지 않습니다.

## 추가하고 사용하기

1. 채팅 입력창의 **+ → 스킬 추가·관리**, 또는 **앱 → 스킬 → 스킬 관리**를 엽니다.
2. Markdown 파일, 스킬 폴더, ZIP·`.skill`·TAR·TAR.GZ·TGZ 압축파일을 업로드합니다. 폴더 선택은 웹에서 지원하며 iOS/Android에서는 파일이나 압축파일을 선택합니다.
3. 채팅에서 `/`를 입력하고 목록에서 스킬을 선택합니다. 웹에서는 Tab으로 첫 번째 검색 결과를 선택할 수도 있습니다.
4. `/code-review 최근 변경 사항을 검토해줘`처럼 보냅니다. `/skill:code-review` 형식도 지원합니다.

지침은 해당 요청에 적용됩니다. 위임한 작업과 그 팀 역할에도 지침을 전달합니다. 다른 대화에는 자동 적용되지 않습니다. 같은 대화에서는 이전 실행 내용이 대화 기록에 남습니다. 일반 모델 대화와 내장 Pi 모두 지원하며, 모델 없이 실행하는 sample 모드는 실제 AI 스킬 실행을 제공하지 않습니다.

관리 화면에서 본문·첨부 파일 목록을 확인하고 활성화·비활성화·삭제할 수 있습니다. 같은 이름을 새 버전으로 바꾸려면 **같은 이름의 스킬 교체**를 선택하고 업로드합니다. 잘못된 묶음은 일부만 등록하지 않습니다.

## 파일 형식

[Agent Skills 형식](https://agentskills.io/specification)의 `SKILL.md`를 사용합니다. 예시:

```markdown
---
name: code-review
description: 코드 변경을 검토하고 문제와 검증 결과를 정리합니다.
---

1. 사용자가 지정한 저장소와 변경 범위를 확인합니다.
2. references/checklist.md를 읽고 코드와 테스트를 검토합니다.
3. 발견한 문제를 중요도 순서로 정리합니다.
4. 실행한 검사와 실행하지 못한 검사를 구분합니다.
```

```text
code-review/
  SKILL.md
  references/checklist.md
  scripts/check.sh
  assets/report-template.md
```

`name`은 영문 소문자·숫자·하이픈으로 1~64자, 설명은 최대 1,024자입니다. 파일명만 있는 간단한 단일 Markdown도 지원합니다. 이 경우 파일명으로 명령 이름을, 본문 첫 줄로 설명을 만듭니다. 한글 파일명을 쓰려면 위처럼 영문 `name`을 지정하세요.

압축파일에는 여러 스킬 폴더를 넣을 수 있습니다. 참고 문서·스크립트·템플릿은 각 스킬의 상대 경로를 유지합니다. 모델은 `list_skills`, `read_skill`, `read_skill_file`로 필요한 부분을 읽습니다. 긴 본문은 미리보기와 파일 읽기를 사용해 요청이 잘리지 않게 합니다. `disable-model-invocation: true`를 지정하면 사용자가 슬래시 명령으로 선택한 경우에만 해당 스킬 파일을 모델에 제공합니다.

업로드만으로 스크립트를 실행하지 않습니다. 실제 실행은 연결된 호스트/컴퓨터 도구를 사용하며 그 실행 환경과 기존 대화 승인 설정을 따릅니다. 스킬은 플러그인 설치나 새로운 도구·계정 권한 부여 기능이 아닙니다.

## 보관과 한도

- 업로드 합계 10MB, 압축 해제 후 20MB, 파일당 2MB, `SKILL.md` 지침 64KB.
- 업로드당 파일 512개·스킬 32개, 보관함 합계 스킬 128개·256MB.
- 경로 이탈·심볼릭 링크·장치 파일·암호화 ZIP·중복 경로는 거부합니다. `.git`, `node_modules`, macOS 메타데이터는 제외합니다.
- 파일은 `DATA_DIR/skills/<소유자 해시>/<버전 ID>`에 저장하고 목록은 기존 DB에 저장합니다. 서버 재시작 후에도 유지되며 백업할 때 DB와 데이터 디렉터리를 함께 보관하세요.
- 진행 중인 작업의 지침은 태스크에 보관됩니다. 스킬 교체 후 이전 버전의 참고 파일을 요구하면 버전 변경을 알리고 새 스킬을 불러오도록 합니다. 삭제·비활성화한 스킬의 추가 파일 읽기는 중단됩니다.

인증된 API: `GET /api/skills`, `POST /api/skills/import` (multipart `files`, 선택적인 JSON `paths`, `replace=true`), `GET/PATCH/DELETE /api/skills/:name`. PATCH는 `{ "enabled": false }`처럼 사용합니다.
