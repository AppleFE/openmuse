# OpenMuse 0.2

## 예약 작업

**일정** 화면에서 한 번 실행, 매일 지정 시간, 5필드 cron과 IANA 시간대를 지정합니다.
채팅에서도 “매일 오전 8시에 연결된 호스트 상태를 점검하고 결과를 정리해줘”처럼 요청하면
AI가 `create_schedule`을 호출해 실제 예약을 등록합니다. 시간이 모호하면 먼저 확인합니다.
예약에서 실행할 모델을 선택할 수 있고 AI 도구에서는 팀도 지정할 수 있습니다.

예약은 DB에 저장하고 서버 시작 후 복구합니다. 실행 시 실제 AI 태스크를 만들고 등록된 도구를
호출합니다. 외부 변경에 검토가 필요한 권한 정책은 예약에서도 적용됩니다. 예약 목록에서
다음 실행, 일시 중지·재개, 수정·삭제와 실행 기록·태스크 결과를 확인합니다. 같은 예약의 이전
작업이 끝나지 않았다면 다음 실행은 건너뜁니다. 서버가 꺼져 있던 기간은 켜진 뒤 한 번만
따라잡으며 밀린 실행을 모두 반복하지 않습니다. 서버가 실행 중이어야 동작합니다.
시간대와 일광절약시간은 cron-parser로 처리합니다.

## 사용량과 채팅

모델 선택 옆의 **사용량**에서 해당 채팅, 전체 채팅, 예약·팀을 포함한 전체 AI 작업의 입력·출력·
캐시·총 토큰과 호출 수를 봅니다. 생성 중 `≈ tok/s`는 생성 텍스트를 이용한 추정값입니다.
완료 후에는 모델이 보고한 출력 토큰과 생성 시간을 이용합니다. 토큰 수를 보고하지 않은 호출은
구분하고 합계에서 제외합니다. 적용 이전 사용량은 소급 집계하지 않습니다. 금액 청구 통계는 아닙니다.
새 메시지는 서버에 발언 시각을 별도로 저장하고 말풍선 옆에 시·분으로 표시합니다.

대화 목록의 **보관함**에서 별도 채팅을 **완전 삭제**할 수 있습니다. 두 번째 확인을 거쳐
메시지·실행 기록·Pi 세션 파일을 삭제합니다. 실행 중이거나 기본 대화인 경우 삭제를 막습니다.
복원 기능은 없습니다. 내용이 없는 사용량 집계 기록은 전체 누적 통계에 남습니다.
