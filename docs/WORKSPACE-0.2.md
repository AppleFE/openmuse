# OpenMuse 0.2 / 0.3

## 채팅별 자동 승인 (0.3)

모델 선택 옆 **승인 설정**에서 **매번 승인 요청** 또는 **자동 승인 (bypass)**을 선택합니다.
설정은 대화별로 서버에 저장되며 새로고침해도 유지됩니다. 실행 중에는 변경할 수 없습니다.
자동 승인은 해당 대화에서 새로 준비한 커넥터·이메일·일정 변경과 그 대화에서 위임한 작업에
적용합니다. 다른 대화나 별도로 만든 예약은 기본 검토 방식을 유지합니다. 보관·삭제한 대화와
취소한 작업에서는 자동 실행하지 않습니다. 기존에 준비된 검토를 설정 변경만으로 실행하지 않습니다.
자동 실행도 동일한 연결·대상 버전 검증과 실행 기록·중복 실행 방지를 사용합니다.
모델의 메시지·도구 인수로 설정을 바꿀 수 없으며 서비스 API의 권한·제품 제한은 그대로 적용합니다.

GitHub의 **공개 포크**는 GitHub 정책상 비공개로 바꿀 수 없습니다. 자동 승인이나 PAT 권한으로
해결되지 않습니다. GitHub의 포크 분리 기능을 확인하거나 별도 비공개 저장소로 복제해야 합니다.
OpenMuse가 이 오류를 이유로 기존 저장소를 삭제·분리·복제하지는 않습니다.

## 공유 브라우저 반응 속도 (0.3)

Chromium이 생성한 최신 JPEG를 noVNC Tight 인코딩으로 전달하며, 매번 PNG를 촬영·디코딩하던
작업을 제거했습니다. 화면 수집은 입력 대기열과 분리하고 변경되지 않은 화면은 재전송하지 않습니다.
전송은 최대 약 15fps이며 느린 연결에서는 오래된 화면과 마우스 이동이 쌓이지 않도록 처리합니다.
키·클릭·드래그 시작과 종료·붙여넣기의 순서는 유지합니다. 네트워크 지연 자체는 남습니다.
Host Agent 0.3.0에서 개선된 화면 수집을 지원합니다. 기존 호스트는 이전 PNG 방식으로 연결할 수
있지만 해당 호스트의 개선을 받으려면 Host Agent도 업데이트해야 합니다.

SSH의 **서버 지문** 입력은 고급 설정으로 옮겼습니다. 기본적으로 개인 키 파일 업로드 또는
비밀번호 입력만 하면 첫 저장 시 서버 지문을 자동 고정합니다. 개인 키는 사용자 로그인용이고
지문은 서버 식별용입니다. 서버 키가 바뀌면 다시 확인한 지문을 고급 설정에 입력해야 합니다.

## 예약 작업

0.10.6부터 **활동 → 예약 작업 관리 · 중지 / 삭제**에서도 예약 목록을 엽니다.
예약으로 생성된 작업의 상세 화면에도 같은 관리 버튼이 있습니다. 기본 목록은 실행 중인
예약만 표시하며 **전체**에서 중지된 예약을 확인·삭제할 수 있습니다. 예약의 단일 실행에는
예약 생성·수정·삭제 도구를 제공하지 않아 실행 때마다 새 예약이 생기는 것을 막습니다.

**일정** 화면에서 한 번 실행, 매일 지정 시간, 5필드 cron과 IANA 시간대를 지정합니다.
채팅에서도 “매일 오전 8시에 연결된 호스트 상태를 점검하고 결과를 정리해줘”처럼 요청하면
AI가 `create_schedule`을 호출해 실제 예약을 등록합니다. 시간이 모호하면 먼저 확인합니다.
예약에서 실행할 모델을 선택할 수 있고 AI 도구에서는 팀도 지정할 수 있습니다.

예약은 DB에 저장하고 서버 시작 후 복구합니다. 실행 시 실제 AI 태스크를 만들고 등록된 도구를
호출합니다. 외부 변경에 검토가 필요한 권한 정책은 예약에서도 적용됩니다. 예약 목록에서
다음 실행, 일시 중지·재개, 수정·삭제와 실행 기록·태스크 결과를 확인합니다. 같은 예약의 이전
작업이 끝나지 않았다면 다음 실행은 건너뜁니다. 서버가 꺼져 있던 기간은 켜진 뒤 한 번만
따라잡으며 밀린 실행을 모두 반복하지 않습니다. 서버가 실행 중이어야 동작합니다.
시간대와 일광절약시간은 cron-parser로 처리합니다.

## 작업 삭제와 알림 확인 (0.10.6)

- 채팅의 업데이트 배너 또는 **알림** 화면에서 **모두 확인**을 누르면 현재 표시 대상 알림을
  한 번에 읽음 처리합니다. 처리 중 새로 도착한 알림은 읽지 않은 상태로 남습니다.
- 알림 화면은 **안 읽음 / 전체**로 전환합니다. 읽음 처리는 작업 취소나 예약 중지를 뜻하지 않습니다.
- **활동 → 작업 열기 → 작업 삭제 → 삭제 확인**으로 작업 기록과 관련 알림을 삭제합니다.
  진행 중이면 **중지 후 삭제 확인**으로 먼저 취소합니다. 취소 마무리 중에는 잠시 후 다시 삭제합니다.
- 생성된 파일과 외부 실행 영수증, 반복 예약 등록은 유지됩니다. 다음 실행까지 중단하려면
  **예약 작업 관리**에서 해당 예약을 중지하거나 삭제합니다.

## 사용량과 채팅

모델 선택 옆의 **사용량**에서 해당 채팅, 전체 채팅, 예약·팀을 포함한 전체 AI 작업의 입력·출력·
캐시·총 토큰과 호출 수를 봅니다. 생성 중 `≈ tok/s`는 생성 텍스트를 이용한 추정값입니다.
완료 후에는 모델이 보고한 출력 토큰과 생성 시간을 이용합니다. 토큰 수를 보고하지 않은 호출은
구분하고 합계에서 제외합니다. 적용 이전 사용량은 소급 집계하지 않습니다. 금액 청구 통계는 아닙니다.
새 메시지는 서버에 발언 시각을 별도로 저장하고 말풍선 옆에 시·분으로 표시합니다.

대화 목록의 **보관함**에서 별도 채팅을 **완전 삭제**할 수 있습니다. 두 번째 확인을 거쳐
메시지·실행 기록·Pi 세션 파일을 삭제합니다. 실행 중이거나 기본 대화인 경우 삭제를 막습니다.
복원 기능은 없습니다. 내용이 없는 사용량 집계 기록은 전체 누적 통계에 남습니다.
