# 원격 호스트 대시보드

**앱 → 인프라 연결 → 원격 호스트 대시보드**에서 연결된 PC·서버를 함께 봅니다. 각 원격 호스트의 **사용량·그래프** 버튼으로 해당 기기를 바로 선택할 수도 있습니다.

- 호스트별 온라인 상태, 연결 주소·방식, 실제 OS·아키텍처·호스트 이름, CPU 모델·논리 코어, 가동 시간
- CPU·메모리 사용률과 최근 5/15/30분 그래프, 사용 가능 메모리와 스왑
- 디스크 읽기·쓰기 전송 속도 그래프와 볼륨별 사용량·여유 공간
- 네트워크 수신·송신 속도 그래프, 인터페이스별 속도·누적 전송량
- 지원되는 하드웨어의 전력(W) 그래프 및 배터리 잔량·충전 상태

화면을 보는 동안 5초 간격으로 갱신하며 호스트를 최대 3대씩 병렬 조회합니다. 느린 연결에서는 실제 간격이 길어질 수 있습니다. 일시 정지 버튼, 앱 백그라운드·웹 탭 숨김·화면 닫기 시 수집을 멈춥니다. 그래프는 조회하는 동안의 최근 30분, 호스트당 최대 360개 표본을 기존 DB에 보관합니다. 24시간 백그라운드 모니터링이나 장기 시계열 저장 기능은 아닙니다.

연결이 끊기면 마지막 측정 시각과 이전 값임을 표시하고 그래프에 빈 구간을 남깁니다. `—`는 첫 표본이라 변화량을 아직 계산하지 못했거나 해당 지표를 수집할 수 없다는 뜻입니다. 실제 값을 0으로 만들어 표시하지 않습니다. 카운터 감소·재부팅·긴 수집 공백에서는 전송 속도를 새로 계산하기 위해 두 표본을 기다립니다.

## 연결 방식과 에너지 측정

Host Agent **0.5.0 이상**은 인증된 `/host/metrics`로 사용량을 제공합니다. 기존 에이전트의 셸·브라우저 기능은 그대로 호환되며, 구버전에는 대시보드에서 업데이트 안내가 표시됩니다. 새 자동 설치 명령과 배포 파일에는 최신 수집기를 포함합니다.

SSH 방식은 설치 없이 등록된 Linux·macOS·Windows에서 고정된 읽기 전용 OS 조회 명령을 실행합니다. 임의의 명령이나 경로는 조회 인수로 받지 않습니다. 지문·인증 검증과 연결 소유자 권한을 그대로 적용합니다. Linux는 `/proc`·`/sys`·df, macOS는 top·vm_stat·ioreg·netstat·df, Windows는 PowerShell CIM을 사용합니다. SSH OS 플랫폼 설정이 실제 대상과 같아야 합니다.

전력은 OS와 센서의 지원·권한에 따라 다릅니다.

| 환경 | 전력 측정 |
| --- | --- |
| 관리자 macOS Host Agent | `powermetrics`가 제공하는 CPU 또는 CPU+GPU+ANE 전력. 지원되는 출력이 있을 때만 W 표시 |
| Linux Host Agent | 읽을 수 있는 RAPL 센서의 CPU 패키지 에너지 변화량으로 W 계산 |
| Windows·SSH·센서 접근 불가 | W는 측정 불가로 표시. 배터리 정보가 제공되면 별도로 표시 |

칩·CPU 패키지 전력은 콘센트에서 측정하는 PC 전체 소비전력과 다릅니다. 자동 sudo나 권한 승격은 하지 않습니다. 관리자 계정으로 구동 중인 에이전트도 실제 하드웨어·센서 지원이 필요합니다.

네트워크 합계에는 VPN·가상 인터페이스의 중복 트래픽이 포함될 수 있으므로 인터페이스별 값도 함께 제공합니다. APFS 등 공유 저장 공간을 사용하는 볼륨은 합산하지 않고 개별 표시합니다. 사용률과 전송 속도는 OS별 정의·표본 시점 차이 때문에 작업관리자/활성 상태 보기와 완전히 일치하지 않을 수 있습니다.

## Host Agent 업데이트

1. 해당 호스트에서 실행 중인 셸 작업과 브라우저 작업이 끝난 뒤 Host Agent 서비스만 중지합니다.
2. [배포 파일](https://github.com/AppleFE/openmuse/releases/tag/host-agent-v0.5.0)을 새 디렉터리에 풀고 `npm ci`를 실행합니다. 기존 `config.json`과 데이터 디렉터리는 유지합니다.
3. 기존 서비스의 실행 경로를 새 `run.mjs`로 연결하거나 기존 코드 파일만 교체하고, 동일한 config 경로로 다시 실행합니다. 재등록이나 새 토큰 발급은 필요하지 않습니다.

실행 경로·서비스 이름·설치 위치는 [원격 호스트 가이드](REMOTE-HOSTS.md)를 참고하세요. 기존 기기 전체를 앱이 자동 업데이트하는 기능은 포함하지 않습니다.

개발 참고: [systeminformation 메모리](https://systeminformation.io/memory.html), [디스크](https://systeminformation.io/filesystem.html), [네트워크](https://systeminformation.io/network.html), [배터리](https://systeminformation.io/battery.html). 에이전트는 이 라이브러리와 고정된 OS 센서 조회를 사용하며 모델 키·환경 변수·프로세스 명령줄을 수집하지 않습니다.
